Yemen AI — Full Project Package
================================

هذا هو المشروع الكامل: React/Vite في الواجهة، Express/tRPC في الخادم، وDrizzle في قاعدة البيانات.

تشغيل محلي:
1. ثبّت Node.js 22 وpnpm.
2. نفّذ: pnpm install
3. جهّز متغيرات البيئة المطلوبة في بيئة الاستضافة.
4. نفّذ: pnpm dev

للإنتاج:
- pnpm build
- pnpm start

المتطلبات:
- استضافة تدعم Node.js.
- متغيرات بيئة Manus/LLM وقاعدة البيانات حسب ملف المشروع.
- لا تضع مفاتيح API داخل client أو dist/public.

الميزات الموجودة:
- محادثة Yemen AI بلهجة يمنية.
- تحليل عبارات اللهجات اليمنية.
- تحويل تسجيل صوتي عربي/يمني إلى نص.
- حاسبة تكلفة وسعر بيع للسوق المحلي.
- تحليل أولي لصورة محصول زراعي.
- واجهة RTL متجاوبة.
