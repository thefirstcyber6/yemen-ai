Yemen AI — InfinityFree Deployment
===================================

هذه الحزمة هي نسخة Static مبنية من الموقع.

طريقة الرفع:
1. فك الضغط.
2. ارفع كل الملفات الموجودة في هذا المجلد إلى مجلد htdocs في InfinityFree عبر File Manager أو FTP.
3. افتح نطاقك.

ربط Backend خارجي:
- افتح الملف config.js بعد الرفع.
- غيّر السطر إلى عنوان Backend العام، مثال:
  window.__YEMEN_API_BASE_URL__ = "https://your-yemen-ai-backend.example.com";
- يجب أن يكون Backend يعمل على Node.js وأن يسمح بـ CORS من نطاق InfinityFree.

ما يعمل:
- الواجهة العربية والتصميم المتجاوب.
- أقسام الموقع والتنقل والبطاقات.
- العرض البصري على الهاتف والكمبيوتر.

ما لا يعمل بدون Backend خارجي:
- محادثة الذكاء الاصطناعي.
- تحويل الصوت إلى نص.
- تحليل صور الزراعة.
- أي إجراء يعتمد على /api/trpc.

السبب: النسخة الحالية تحتاج خادم Node.js وبيئة Server-side لحماية مفاتيح الذكاء الاصطناعي، وInfinityFree المجانية لا تستضيف Node.js. لا تضع مفاتيح API داخل ملفات JavaScript العامة.

لتشغيل جميع الميزات:
- ارفع مجلد المشروع الكامل إلى استضافة تدعم Node.js، أو
- انقل الإجراءات الخلفية إلى PHP/API منفصل مع حفظ المفاتيح على الخادم.

تم اختبار نسخة البناء محليًا بنجاح قبل إنشاء هذه الحزمة.
